# Проект E-commerce Ядро

## Описание
Базовое ООП-ядро для интернет-магазина. Реализована структура категорий и товаров.

## Функционал
- Созданы базовые классы `Product` (Товар) и `Category` (Категория) с типизацией данных.
- Реализован автоматический подсчет общего количества категорий и уникальных товаров на уровне атрибутов класса при инициализации объектов.
- Добавлена утилитарная функция для импорта и инициализации объектов данных из формата JSON (`src/utils.py`).
- Написаны unit-тесты с использованием `pytest`, обеспечивающие 100% покрытие функционального кода.
- Настроена проверка стиля кода линтером `flake8` в соответствии с PEP 8.
